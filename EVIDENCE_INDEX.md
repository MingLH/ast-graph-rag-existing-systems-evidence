# Section 2.3: claim-to-evidence index

This index is designed to accompany the latest draft, **Section 2.3**. Each row states what the review claims, identifies the supporting evidence and specifies what the evidence **does not** establish. Claims concerning tool design come from the developer's repository documentation; independent experimental observations come from files in this archive.

## What this index does and does not verify

- **Observed (OBS):** A claim has recorded executed experiment output and an identified input or test context.
- **Inspected/documented (INS):** A capability is described in pinned upstream documentation/implementation, but was not necessarily executed in the local experiment.
- **Not established (NE):** The evidence does not support a wider inference; this is **not** a statement that the software lacks the capability.

The indexed test evidence supports the *narrow observations* described above, not comparative precision/recall/F1, statistical superiority, real live embedding relevance, full BookStack application indexing, runtime execution traces, or a user study. The experiments do not cover the AST-Graph RAG prototype's eventual performance. Additional experimental interpretation and environment details are in [the technical evidence register](notes/Technical_Evidence_Register.md).
